**S16 — Estado compartido único entre archivos de test.** "Los tests del guard SSRF suelen tocar variables de entorno (`DISABLE_ENTRY_GUARD_ENV` y los hatches) y el registro `OnceLock`. **S17 — Paridad junta y última (refuerza S11).** "Son los que existen para detectar deriva entre el guard y la capa de dial (`seed_guard_refusal_agrees_with_the_enforcing_guard`, `the_dial_layer_always_denied_set_covers_every_never_allowable_range`).
