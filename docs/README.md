# Documentation map — WebFang

This page is the index of where repository knowledge lives and, for the parts that stay
outside `docs/`, why. It exists so the next person does not have to rediscover the
constraints: several of the directories that look like loose documentation are read by
compilation, by fail-closed CI gates, or are deliberately ignored.

## Inside `docs/`

| Path | What it holds | Notes |
| :--- | :--- | :--- |
| `src/` | The mdBook: narrative documentation, CLI reference, troubleshooting, the state recovery runbook | `docs/book.toml` sets `src = "src"`. Chapters are listed in `docs/src/SUMMARY.md` |
| `adr/` | Architecture Decision Records | 21 files plus `README.md`. Not a contiguous range and not renumbered — see `docs/adr/README.md` |
| `architecture/` | Design documents and mechanism descriptions | Includes the crawl-session spec set under `p62-crawlsession-rc2/` |
| `specifications/` | Written decisions with a chosen option, and conventions others must follow | E.g. `llm-backend-decision.md` |
| `research/` | Studies and audits that inform decisions | Self-contained dated studies live in their own subdirectory |
| `samples/` | Shell snippets included verbatim into book chapters | Must stay a sibling of `src/`: 28 `{{#include ../samples/…}}` directives resolve relative to the chapter file |
| `security/` | Prompt-injection policy | Read before acting on an MCP tool result |
| `manual/`, `ci-metrics/` | Operational manuals and gate timing output | `ci-metrics/fast-gate.log` is appended by `scripts/ci_fast_gate.sh` and never versioned |

Reference pages that live at the top of `docs/` (not in the book) are there because a gate or
a compiler reads their exact path. Do not relocate them without editing their reader:

| File | Read by |
| :--- | :--- |
| `error-classification-matrix.md` | `include_str!` in `crates/webfang_core/src/cli/error_matrix_tests.rs` |
| `test-inventory.md` | `scripts/check_ignored_guard.sh` (parses the `Total:` line and the row composition); `test-inventory.json` is generated by `scripts/ci_test_inventory.py` |
| `ssrf-layers.md` | Thirteen referrers, including a user-facing CLI error message (`crates/webfang_core/src/cli/error.rs`) frozen in a snapshot test |
| `persistence-resume.md` | Cited by `docs/src/state-recovery-runbook.md` and by crash-matrix test messages |

## Deliberately outside `docs/`

| Location | Why it stays where it is |
| :--- | :--- |
| `evidence/` | Frozen mission records. `AGENTS.md`: annotate, never rewrite. Also compile-time (`include_str!` for the mode-D fixtures) and gate-read (`scripts/check_migration_evidence.sh`, blocking while `evidence/mig-2026-01/TRAIN_OPEN` exists) |
| `COMPATIBILITY-MATRIX.md`, `SUPPORT.md`, `AGENTS.md`, `README.md` | Root contracts. `SUPPORT.md` is generated by `scripts/render-support-md.sh` and must never be hand-edited |
| `CHANGELOG.md` | Single writer: the Release PR |

Audit reports are not kept in this repository at all: they live in a sibling `webfang-audit/`
directory outside the tree, and `.gitignore` root-anchors that name so an in-repo copy can
never be committed by accident.

## Adding documentation

- A narrative page belongs in `docs/src/` and must be listed in `docs/src/SUMMARY.md`. A
  chapter missing from the summary is a chapter nobody finds.
- A decision belongs in `docs/adr/`. A convention others must follow belongs in
  `docs/specifications/`.
- Every claim in an operational runbook is pinned by a test. If a behaviour has no test, the
  page says so explicitly rather than promising it.
